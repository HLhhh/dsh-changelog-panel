# dsh-changelog-panel

[English](README.md)

> GitHub 主仓：<https://github.com/HLhhh/dsh-changelog-panel> ·
> Gitee 镜像：<https://gitee.com/huang-lin-java/dsh-changelog-panel>

**给 DeepSeek Harness 用的中英双语「更新日志 / 漏洞公告 / 存储占用」面板。** 装上之后，左侧栏多一个入口，
点开就能看每个版本改了什么、有哪些 CVE/GHSA 影响本机、以及 DSH 在你磁盘上留下了多少东西。

- 版本时间轴 + 按分类分组的特性卡片 + 关键字搜索
- 「漏洞与安全」标签页：13 条公告，带严重级别、影响范围、修复版本与外链
- 本机安装版本徽章，并标出与官方最新版的关系
- 面板自带中英切换，不跟随全局也不会污染全局
- 另附存储看板：DSH 在本地磁盘留下了什么、各占多少、属于哪个对话、哪些可以回收

## 安装 / 更新

> 本插件**尚未发布到 npm**，目前通过 GitHub 安装。

### 用 `dsh` 命令行安装

```sh
dsh plugin --profile web add github:HLhhh/dsh-changelog-panel
```

profile 名按你的实际情况替换（桌面版通常是 `desktop`，网页版通常是 `web`）。

### 用 `plugin_manager` 工具安装（Agent 里）

让 Agent 调用 `plugin_manager` 的 `install_bundle`，`target` 传：

```
github:HLhhh/dsh-changelog-panel
```

### 从本地目录安装

```sh
git clone https://github.com/HLhhh/dsh-changelog-panel.git
dsh plugin --profile web add /绝对路径/dsh-changelog-panel
```

仓库里已经带好构建产物 `lib/client.js`，**安装不需要构建环境**。
装完重启 DSH（或等 HMR 生效），刷新页面即可在侧栏看到图标。

卸载：

```sh
dsh plugin --profile web remove dsh-changelog-panel
```

## 功能

### 更新日志

- 左侧版本时间轴，默认定位到**本机安装的版本**
- 中间按分类分组：智能体 / 界面 / 工具 / 会话 / 安全 / 平台 / 插件
- 顶部搜索框，按标题、摘要、相关包名过滤
- 单个版本最多渲染 12 条 release，更早的在左侧版本栏切换

### 漏洞与安全

- 13 条安全公告与 CVE/GHSA 记录，每条含严重级别、状态、影响范围、修复版本、外链
- 额外显示「检索范围说明」：搜了什么、没找到什么，不做无根据的断言

### 实时数据

面板会**直接**从两个公开接口拉取最新数据（浏览器直连，不经过任何第三方服务器）：

| 来源 | 用途 |
| --- | --- |
| `registry.npmjs.org/@deepseek-ai/dsh-base` | 版本总表与发布时间 |
| `api.github.com/repos/deepseek-ai/deepseek-harness/releases` | 官方更新日志正文 |

- 每天首次打开面板自动刷新一次；顶部有**手动刷新**按钮和上次刷新时间
- 拉到的版本会并入左侧版本栏，但**不会覆盖**已核对过的内置数据集
- 遇到速率限制会明确提示，不会静默失败

### 存储看板

同一插件附带的存储视图：显示 DSH 在本地磁盘上留下了什么（会话日志、附件、缓存、运行时等）、
各占多少容量、属于哪个对话、哪些可以回收到「废纸篓」。**只报告，不替你删**，
不可回收的类别会直接标注原因。

## 配置

本插件没有配置项，装上即用。语言是面板自己的状态（右上角「中文 / EN」），
默认跟随 GUI 语言，切换只影响这块面板。

## 兼容性

| 项 | 状态 |
| --- | --- |
| DeepSeek Harness | `0.2.x`（开发与实测于 `0.2.1-rc.2`） |
| Node | `^22.19.0 \|\| >=24.0.0` |
| 平台 | Web（网页版 / 桌面版） |
| 依赖 | 仅对等依赖 `@deepseek-ai/cordis ~4.0.4`，不打包任何宿主包 |

## 已知限制

- **尚未发布 npm**：只能通过 GitHub 或本地路径安装
- 内置数据集是某个时间点的快照；要看当前版本请用「手动刷新」拉实时数据
- 实时拉取依赖 `api.github.com` 与 `registry.npmjs.org` 的可达性；网络受限时只显示内置数据
- 存储看板的容量数字完全来自扫描当次的报告，不做推算
- 中文条目是**转述**而非公告原文引用，正式合规判断请以外链原文为准

## 开发

```bash
# 重新生成 lib/client.js（源码在 src/）
npm run build

# 校验数据集
npm run data:verify
```

`lib/client.js` 是构建产物，请改 `src/` 后重新构建，不要手改产物。
